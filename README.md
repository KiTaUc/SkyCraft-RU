# SkyCraft

![SkyCraft: игрок Minecraft идёт по Ривервуду в Skyrim с интерфейсом Minecraft](docs/screenshot.jpg)

Играйте в Skyrim как персонаж Minecraft: перемещайтесь с физикой Minecraft, пользуйтесь инвентарём и интерфейсом Minecraft, размещайте и добывайте блоки в мире Skyrim. Сражайтесь с персонажами Skyrim оружием Minecraft — и получайте отпор.

Игры не переписываются. Minecraft выполняет собственную игровую логику, а Skyrim отвечает за свой мир, NPC, задания и сохранения. Плагин SKSE для Skyrim и мод Fabric для Minecraft обмениваются данными через общую память. Minecraft работает скрытно в фоновом режиме, а изображение выводит Skyrim.

> **Статус: ранняя экспериментальная версия.** Возможны ошибки и нестабильная работа; делайте резервные копии сохранений.
> Это фанатский проект, не связанный с Mojang, Microsoft, Bethesda или ZeniMax. Для игры необходимо владеть обеими играми.

## Что уже работает

- **Передвижение:** физика Minecraft применяется к ландшафту и зданиям Skyrim. Доступны ходьба, бег, прыжки, приседание, плавание и падение. Коллизии Skyrim передаются в систему столкновений Minecraft.
- **Блоки:** размещайте и ломайте блоки в мире Skyrim. Они отрисовываются в кадре Skyrim с его солнцем, тенями, туманом и погодой. Источники света Minecraft (факелы, лава, светокамень и другие) освещают Skyrim.
- **Добыча объектов Skyrim:** добывайте землю, камни, дороги и объекты Skyrim как блоки Minecraft. Извлечённый блок соответствует материалу объекта: например, сначала земля под травой, затем камень с рудами и бедрок. Образовавшаяся яма реальна для игрока, NPC и предметов. TNT, криперы и другие взрывы оставляют кратеры в Skyrim. За стенами интерьеров и пещер находится сплошной камень. Результаты добычи сохраняются в мире Minecraft. Переключатель **«Разрушение Skyrim: Вкл./Выкл.»** в левом верхнем углу меню паузы (клавиша **O**) отключает разрушение; уже выкопанные ямы остаются.
- **Блочные сущности:** отрисовываются сундуки, кровати, знамёна, головы, шалкеровые ящики и похожие блоки; поршни перемещают блоки.
- **Вода и лава:** жидкости текут по ландшафту Skyrim, а в воде Skyrim персонаж плавает как в Minecraft.
- **Бой:** атакуйте NPC Skyrim любым оружием Minecraft, включая луки, трезубцы и TNT. Урон зависит от уровня NPC, а противники дают сдачи.
  - NPC сталкиваются с блоками и обходят их.
  - Лава и огонь наносят NPC урон; NPC нажимают нажимные плиты.
- **Развитие персонажа Skyrim:**
  - Играя в Minecraft, вы повышаете навыки Skyrim. Мечи, булавы и инструменты развивают навык «Одноручное оружие»; топоры и копья — «Двуручное оружие»; луки и метательное оружие — «Стрельба».
  - Щиты развивают «Блокирование», а получаемые удары — «Лёгкую броню» или «Тяжёлую броню» в зависимости от экипировки.
  - Создание снаряжения развивает «Кузнечное дело», а приседание работает как скрытность Skyrim и развивает навык «Скрытность».
- **Камера и смерть:** режимы камеры Minecraft (клавиша **F5**) показывают в Skyrim ваш скин и броню. При смерти включается камера смерти Skyrim, а тело персонажа Minecraft падает с физикой ragdoll.
- **Анимации Skyrim:** при использовании стульев, верстаков, кроватей, рычагов и лошадей, а также во время сценарных сцен управление временно передаётся Skyrim.
- **Мультиплеер (только со стороны Minecraft):** друзья с установленным SkyCraft могут подключаться к вашему миру Minecraft через интернет (см. раздел [«Игра с друзьями»](#игра-с-друзьями)).

## Требования

### Skyrim

| Требование | Примечания |
|---|---|
| Skyrim Special Edition с рантаймом **Anniversary Edition** (1.6.x / 1.7.x) | Разработка и тестирование проводились на версии **1.7.104**. Skyrim SE 1.5.97 и Skyrim VR не поддерживаются. |
| [SKSE64](https://skse.silverlock.org/) | Версия должна соответствовать вашей версии игры. |
| [Address Library for SKSE Plugins](https://www.nexusmods.com/skyrimspecialedition/mods/32444) | Установите файл **All in one (Anniversary Edition)**. |

> **Настоятельно рекомендуется [Alternate Start - Live Another Life](https://www.nexusmods.com/skyrimspecialedition/mods/272).** Начало Skyrim (поездка на телеге и Хелген) сильно зависит от скриптов и может работать неправильно с SkyCraft — персонаж может застрять. Alternate Start позволяет пропустить вступление и выбрать место начала новой игры. Другой вариант — загрузить сохранение, созданное после Хелгена.

### Minecraft

Нужна только **учётная запись Microsoft, которой принадлежит Minecraft: Java Edition**. В комплект SkyCraft входят портативный [Prism Launcher](https://prismlauncher.org/), настроенный для Minecraft 26.3, [Fabric](https://fabricmc.net/), [Fabric API](https://modrinth.com/mod/fabric-api) и мод SkyCraft для Minecraft. Prism самостоятельно скачивает Minecraft и Java.

Minecraft скрытно работает параллельно со Skyrim. Рекомендуется выделить около **3 ГБ дополнительной оперативной памяти**, примерно **1,5 ГБ на диске** для файлов Minecraft и видеокарту, способную запускать Minecraft 26.3.

## Установка

> Для обычной установки нужен готовый архив `SkyCraft-<версия>.zip` из раздела релизов. Архив с исходным кодом из этого репозитория сам по себе не является готовым модом для установки.

1. **Установите `SkyCraft-<версия>.zip`** через Mod Organizer 2 или Vortex, как любой плагин SKSE.
2. **Запустите Skyrim через SKSE.** При первом запуске SkyCraft распакует Minecraft в `%LOCALAPPDATA%\SkyCraft`. Откроется небольшое окно **Prism Launcher** с просьбой войти в учётную запись Microsoft. Переключитесь на него сочетанием **Alt+Tab**, войдите в аккаунт и вернитесь в Skyrim. Prism скачает Minecraft, Fabric и Java (при первом запуске это займёт несколько минут). Сообщения в углу экрана Skyrim сообщат, когда Minecraft будет готов.
3. **При следующих запусках всё происходит автоматически.** Minecraft запускается вместе со Skyrim без отдельного окна и звука, самостоятельно открывает мир SkyCraft (новый мир в режиме «Выживание», созданный на вашем компьютере) и закрывается вместе со Skyrim.

### Обновление и удаление

- **Обновление:** установите новый архив SkyCraft поверх старого. При следующем запуске обновится и часть Minecraft; вход в аккаунт и ваш мир сохранятся.
- **Удаление:** удалите мод в Mod Organizer 2 или Vortex, затем удалите папку `%LOCALAPPDATA%\SkyCraft`. В ней находятся Prism, данные входа в Microsoft (хранящиеся Prism), файлы Minecraft и мир SkyCraft.

### Использование собственного лаунчера

В `Data/SKSE/Plugins/SkyCraft.ini` можно указать собственный Prism, MultiMC или файл `.bat`:

```ini
[Minecraft]
bStartWithSkyrim = 1              ; 0: запускать Minecraft самостоятельно любым способом
sLauncher =                       ; пусто: использовать Minecraft из комплекта SkyCraft
sArguments = --launch SkyCraft    ; аргументы для запуска экземпляра SkyCraft
```

Экземпляру потребуются Minecraft 26.3, Fabric Loader версии 0.19.5 или новее, Fabric API, Java 25 и файл `skycraft-fabric-<версия>.jar` из релиза. Если Minecraft должен оставаться скрытым с самого начала, добавьте в аргументы JVM параметр `-Dskycraft.startHidden=true`. SkyCraft не запускает второй экземпляр Minecraft, если уже работает экземпляр с этим модом. Minecraft запускается через оболочку Windows, поэтому при использовании Mod Organizer он остаётся вне виртуальной файловой системы MO2 и не блокирует менеджер модов.

## Игра с друзьями

Каждому игроку нужны собственная Skyrim и установленный SkyCraft. Общим является только мир Minecraft: блоки, предметы, существа и игроки. Поддерживается до 100 игроков. Мир Skyrim, NPC и задания у каждого остаются собственными.

1. **Хост:** нажмите **O** (меню Minecraft), выберите **Open to LAN**, затем **Start LAN World**. Встроенный в SkyCraft [e4mc](https://modrinth.com/mod/e4mc) отправит в чат ссылку вида `abc-def.e4mc.link`. Нажмите на неё, чтобы скопировать, и отправьте друзьям.
2. **Подключающиеся игроки:** нажмите **T** и введите `/join abc-def.e4mc.link`. Ваш Minecraft покинет собственный мир и подключится к миру хоста.
3. Команда **`/leave`** вернёт вас в собственный мир. Если хост закроет свой мир, гости автоматически вернутся в свои миры.

**Через Discord:** во время игры ваш статус Discord показывает SkyCraft. После открытия мира для локальной сети появляется кнопка **Join**; также можно пригласить друзей из чата Discord. Другу, у которого уже запущены Skyrim и SkyCraft, достаточно нажать эту кнопку — ссылка не нужна.

## Управление

Основное управление принадлежит Minecraft. Следующие клавиши по-прежнему передаются Skyrim:

| Клавиша | Действие |
|---|---|
| **G** | Взаимодействие в Skyrim: двери, NPC (разговор), контейнеры, рычаги и мебель |
| **Esc** | Меню Skyrim (или закрытие открытого экрана Minecraft) |
| **J / M** | Журнал / карта Skyrim |
| **H** | Ожидание в Skyrim |
| **F9** | Быстрая загрузка Skyrim (сохранение из меню Esc) |
| **~** | Консоль Skyrim |
| **O** | Меню паузы и настроек Minecraft |

Все остальные клавиши управляют Minecraft: **E** — инвентарь, **F5** — камера, **T** — чат, **/** — команды, **Shift** — присесть / красться и так далее.

## Известные ограничения

- Если возникла проблема, смотрите журнал `Documents\My Games\Skyrim Special Edition\SKSE\SkyCraft.log`. Для подробных журналов перед отправкой сообщения об ошибке установите `bDiagnostics = 1` в `SkyCraft.ini`.
- **Застряли на сообщении «SkyCraft: starting Minecraft...»?** Примерно через минуту SkyCraft сообщит, что произошло:
  - Prism Launcher всё ещё занят: переключитесь на него через Alt+Tab — он может скачивать файлы, ожидать входа в аккаунт или показывать ошибку.
  - Minecraft закрылся. Его журнал находится в `%LOCALAPPDATA%\SkyCraft\Prism\instances\SkyCraft\.minecraft\logs\latest.log`.
  - Minecraft запущен, но не отвечает. При сообщении об ошибке приложите `SkyCraft.log` и `latest.log`.
- Для работы необходимо владеть Minecraft: Java Edition.
- Вступление Skyrim (поездка на телеге и Хелген) может привести к зависанию. Используйте [Alternate Start](https://www.nexusmods.com/skyrimspecialedition/mods/272) или сохранение, сделанное после Хелгена.
- Пока Minecraft управляет персонажем, нельзя открыть инвентарь, магию, крики и перки Skyrim.
- Удары Minecraft попадают только по NPC, но не по объектам Skyrim — например, паутине вокруг Арвела в Кургане Погребальных Песен. Игрового переключателя для возврата к обычному Skyrim пока нет. Закрытие Minecraft возвращает управление Skyrim; Minecraft сохраняет данные при автосохранении раз в несколько минут. Взаимодействуйте с таким объектом, затем перезапустите Skyrim, чтобы снова запустить Minecraft.
- Текст на табличках пока не отображается.
- Все интерьеры Skyrim используют один мир Minecraft, поэтому блоки, поставленные в разных интерьерах на одинаковых координатах, могут совпадать.
- В мультиплеере синхронизируется только мир Minecraft. У каждого игрока свой Skyrim, и гости пока не могут атаковать NPC в своём мире Skyrim.
- Моды, которые также перехватывают камеру (Improved Camera SE, SmoothCam, True Directional Movement), будут конфликтовать со SkyCraft.

## Сборка из исходного кода

Для сборки на Windows нужны **Visual Studio 2026** с компонентами C++, **CMake 3.25 или новее**, **Git** и **JDK 25**. Также собирается зависимость CommonLibSSE-NG (подмодуль Git) и используется vcpkg.

```bat
git clone --recursive https://github.com/KiTaUc/SkyCraft-RU.git skycraft
cd skycraft
git clone https://github.com/microsoft/vcpkg .tools\vcpkg
.tools\vcpkg\bootstrap-vcpkg.bat

cd skse
cmake --preset default
cmake --build --preset release

cd ..\fabric
gradlew build

cd ..
powershell -ExecutionPolicy Bypass -File tools\package.ps1 -NoBuild
```

Скрипт `tools\package.ps1` собирает обе части проекта (уберите параметр `-NoBuild`, чтобы запустить сборку автоматически) и записывает готовые файлы релиза в `dist\`.

Для разработки:

- `fabric\gradlew runClient` запускает тестовый Minecraft для разработки; он продолжает работать после закрытия Skyrim.
- Если задана переменная `SKYCRAFT_DEPLOY_DIR` (по умолчанию используется папка мода MO2 `mods\SkyCraft`, если она существует), каждая сборка плагина копируется непосредственно в Mod Organizer.
- В `docs\DESIGN.md` описано взаимодействие двух частей проекта, а `protocol\skycraft_protocol.h` содержит схему общей памяти, которой следуют обе стороны.

| Папка | Содержимое |
|---|---|
| `skse/` | Плагин SKSE для Skyrim (C++, [CommonLibSSE-NG](https://github.com/alandtse/CommonLibVR/tree/ng)) |
| `fabric/` | Мод Fabric для Minecraft (Java) |
| `protocol/` | Протокол общей памяти между двумя частями |
| `tools/` | Упаковка, тестовые заглушки (`fake_skyrim.py`, `fake_guest.py`) и диагностические утилиты |
